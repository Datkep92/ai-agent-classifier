7. KNOWN ISSUES
- Real provider calls require an origin the provider allows. GitHub
  Pages may be rejected by some providers due to CORS. A local server
  or a small proxy avoids this.
- The jailbroken Node runtime cannot run node:http or global fetch
  because WebAssembly is disabled. Browser use is unaffected.
- No browser was available here, so the UI was verified by serving
  assets and checking module resolution, not by visual render.
